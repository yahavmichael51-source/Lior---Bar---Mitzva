# אתר אישור הגעה לבר המצווה

אתר קטן ומותאם לטלפון: אורחים ממלאים שם פרטי ובוחרים ״מגיע/ה״, ״לא מגיע/ה״ או ״עוד לא יודע/ת״. מי שבוחר ״מגיע/ה״ בוחר גם כמה אנשים יגיעו: ״רק אני״, ״אני + 1״ או ״אני + 2״ (כלומר 1, 2 או 3 אנשים).

- **עמוד האורחים:** `/`
- **עמוד המנהל:** `/admin`. הוא מוגן בסיסמה שנשמרת רק בשרת. בעמוד יש ארבעה מונים, טבלה עם סינון, ייצוא ל־CSV, עריכה ומחיקה של תשובות, ועריכה של שם הילד, התאריך והמיקום שמוצגים לאורחים.

האתר לא מאחד תשובות של אורחים עם אותו שם. כל שליחה נשמרת כשורה נפרדת.

## הגדרות (משתני סביבה)

| משתנה | חובה? | מה זה |
|---|---|---|
| `ADMIN_PASSWORD` | כן | הסיסמה לעמוד המנהל |
| `DATABASE_URL` | באתר מפורסם: כן | כתובת חיבור למסד נתונים PostgreSQL. בלי המשתנה הזה התשובות נשמרות בקובץ SQLite מקומי (`data/rsvp.db`) |
| `SESSION_SECRET` | מומלץ | מחרוזת אקראית ארוכה לחתימה על עוגיית ההתחברות |
| `PORT` | לא | ברירת המחדל היא 3000 |

## הרצה במחשב

צריך Node.js בגרסה 22.13 ומעלה.

```bash
npm install
ADMIN_PASSWORD=הסיסמה-שלי npm start
# ואז לפתוח את http://localhost:3000 ואת http://localhost:3000/admin
```

## פרסום לאינטרנט (Render + מסד נתונים חינמי ב־Neon)

1. פותחים מסד נתונים חינמי ב־[neon.tech](https://neon.tech) ומעתיקים את ה־connection string (מתחיל ב־`postgresql://`).
2. ב־[render.com](https://render.com) בוחרים **New → Blueprint** ואז את המאגר הזה. הקובץ `render.yaml` מגדיר את השירות.
3. כשמתבקשים, מזינים את `ADMIN_PASSWORD` ומדביקים את הכתובת מ־Neon ב־`DATABASE_URL`.
4. אחרי הפריסה נכנסים ל־`/admin`, פותחים את ״פרטי האירוע שמוצגים לאורחים״ וממלאים תאריך ומיקום.
5. שולחים לאורחים את הכתובת הראשית של האתר.

> חשוב: בשרת המפורסם חייבים להגדיר `DATABASE_URL`. בשירותי אירוח חינמיים הדיסק נמחק בכל הפעלה מחדש, ולכן קובץ SQLite מקומי לא ישמור את התשובות לאורך זמן. אפשר להשתמש גם ב־Postgres של Render, אבל המסלול החינמי שלהם מוגבל בזמן.
>
> בשירות החינמי של Render השרת ״נרדם״ אחרי זמן בלי כניסות, ולכן הכניסה הראשונה אחרי הפסקה עלולה לקחת כחצי דקה.

## בדיקות

```bash
npm install
npm test                      # בדיקה מקצה לקצה בדפדפן, עם SQLite זמני
TEST_DATABASE_URL=postgres://... npm test   # אותה בדיקה מול Postgres
```

הבדיקה שולחת תשובות מכל שלוש האפשרויות ובודקת את הספירה של ״אני + 1״ ו״אני + 2״. היא גם בודקת שהתשובות מופיעות בדוח המנהל אחרי רענון, ושהסינון, ייצוא ה־CSV, העריכה, המחיקה וההגנה בסיסמה עובדים.
